# License Matrix

This repository uses a split-license model by component.

| Component | Paths | License |
|---|---|---|
| TypeScript orchestration | root files, `src/`, `scripts/` | [AGPL-3.0-only](./LICENSE) |
| Rust kernel (`sgrs-core`) | `sgrs-core/` | [Elastic License 2.0 (ELv2)](./sgrs-core/LICENSE) |
| Kernel internal clients | `packages/sgrs-client/`, `packages/sgrs-client-py/` | [MIT](./packages/sgrs-client/LICENSE) |

If there is any discrepancy between this summary and license files, the license file in each component directory is authoritative.
